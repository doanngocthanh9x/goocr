# GoOCR - gRPC File & JSON Transfer System

Hệ thống gRPC cho phép Go client gửi file và JSON tới Python server để xử lý.

## 🏗 Cấu trúc dự án chi tiết

```
goocr/
│
├── proto/                       # 📋 Proto definitions
│   ├── data_transfer.proto      # Main service (ProcessFile, ProcessJson)
│   └── common.proto             # Shared messages (ProcessingStatus, Metadata)
│
├── python_server/               # 🐍 Python gRPC Server
│   ├── server.py                # Main entry point - gRPC server implementation
│   ├── handlers/                # Business logic layer
│   │   ├── file_handler.py      # File processing logic
│   │   ├── json_handler.py      # JSON processing logic
│   │   └── __init__.py
│   ├── config/                  # Configuration
│   │   └── __init__.py          # Server config (host, port, workers)
│   ├── generated/               # Auto-generated by protoc
│   │   ├── common_pb2.py        # Common message definitions
│   │   ├── data_transfer_pb2.py # Service message definitions
│   │   └── data_transfer_pb2_grpc.py  # gRPC service stubs
│   └── requirements.txt          # Python dependencies
│
├── cmd/client/                  # 🐹 Go Client
│   ├── main.go                  # Entry point
│   └── client.go                # Client implementation (File & JSON)
│
├── common/                       # 🔧 Generated - Common package
│   ├── common.pb.go            # Common proto generated code
│   └── go.mod                  # Local module definition
│
├── datatransfer/                # 🔧 Generated - DataTransfer package
│   ├── data_transfer.pb.go     # Proto generated code
│   ├── data_transfer_grpc.pb.go # gRPC generated code
│   └── go.mod                  # Local module definition
│
├── scripts/                     # 🛠 Automation scripts
│   ├── gen_proto.sh            # Generate gRPC code (Python & Go)
│   └── run_server.sh           # Run Python server
│
├── go_client/                   # 📦 Legacy (kept for reference)
│   └── generated/              # Old generated files location
│
├── Makefile                     # 📝 Build commands
├── go.work                      # 🔗 Go workspace configuration
├── go.mod                       # Go main module definition
├── go.sum                       # Go dependencies lock file
├── setup.sh                     # ⚙️ One-command setup
├── requirements.txt             # Python dependencies
└── README.md                    # This file
```

## 📊 Module Architecture

```
┌─────────────────┐
│   Go Client     │ (cmd/client/)
│   main.go       │
└────────┬────────┘
         │ gRPC calls
         ▼
┌─────────────────────────────────────┐
│  Python gRPC Server (port 50051)    │
│  server.py                          │
├─────────────────────────────────────┤
│  Handlers (Business Logic)          │
│  ├── FileHandler                    │
│  └── JsonHandler                    │
└─────────────────────────────────────┘
```

## 📋 Yêu cầu hệ thống

- **Python 3.8+** với `pip`
- **Go 1.19+**
- **protoc** (Protocol Buffer compiler)
- **Linux/macOS** (hoặc WSL2 trên Windows)

## 🚀 Quick Start

### Cách 1: Tự động (Recommended)

```bash
chmod +x setup.sh
./setup.sh
```

Sau đó:
```bash
# Terminal 1
make server

# Terminal 2
make client
```

### Cách 2: Manual setup

```bash
# 1. Cài đặt Python dependencies
pip install -r requirements.txt

# 2. Cài đặt Go dependencies
go mod download

# 3. Generate gRPC code từ proto files
chmod +x scripts/gen_proto.sh
./scripts/gen_proto.sh
```

### 4. Chạy Python gRPC Server

**Terminal 1:**
```bash
./scripts/run_server.sh
```

Output mong muốn:
```
Starting Python gRPC Server...
2025-12-06 04:04:33,947 - __main__ - INFO - Server listening on 0.0.0.0:50051
```

### 5. Chạy Go Client

**Terminal 2:**
```bash
go run ./cmd/client/...
```

Expected output:
```
2025/12/06 04:09:19 Connecting to server: localhost:50051
2025/12/06 04:09:19 Connected to gRPC server
=== Test 1: Processing JSON ===
=== Test 2: Processing File ===
```

## 🔧 Cấu hình Chi Tiết

### Python Server Config

Edit `python_server/config/__init__.py`:

```python
GRPC_SERVER_HOST = "0.0.0.0"   # Host to listen on
GRPC_SERVER_PORT = 50051        # Port
GRPC_MAX_WORKERS = 10           # Thread pool size
GRPC_ENABLE_TLS = False         # Enable TLS/SSL
```

Hoặc dùng environment variables:
```bash
export GRPC_SERVER_HOST=0.0.0.0
export GRPC_SERVER_PORT=50051
export GRPC_MAX_WORKERS=10
export GRPC_ENABLE_TLS=false
```

### Go Client Config

Edit file hoặc dùng environment variables:
```bash
export GRPC_SERVER_HOST=localhost
export GRPC_SERVER_PORT=50051
```

## 🔄 Proto Modification Workflow

Quy trình thêm feature mới:

### 1. Sửa proto file

Edit `proto/data_transfer.proto` hoặc `proto/common.proto`:

```protobuf
// Ví dụ: Thêm RPC method mới
service DataTransferService {
  rpc ProcessFile(stream FileChunk) returns (ProcessFileResponse) {}
  rpc ProcessJson(JsonRequest) returns (JsonResponse) {}
  rpc ProcessImage(ImageRequest) returns (ImageResponse) {}  // NEW
}
```

### 2. Generate code từ proto

```bash
make proto-gen
# hoặc: ./scripts/gen_proto.sh
```

Generated files:
- Python: `python_server/generated/*pb2*`
- Go: `common/` và `datatransfer/` folders

### 3. Implement Python handler

Edit `python_server/handlers/` - tạo file mới:

```python
# python_server/handlers/image_handler.py
class ImageHandler:
    @staticmethod
    def process_image(image_data: bytes, filename: str) -> dict:
        # Your business logic here
        return {"result": "processed"}
```

### 4. Implement Python servicer

Edit `python_server/server.py` - thêm method:

```python
def ProcessImage(self, request, context):
    try:
        result = ImageHandler.process_image(...)
        response = data_transfer_pb2.ImageResponse()
        response.status.status = common_pb2.ProcessingStatus.SUCCESS
        return response
    except Exception as e:
        # Handle error
        pass
```

### 5. Implement Go client

Edit `cmd/client/client.go`:

```go
type ImageClient struct {
    conn *grpc.ClientConn
}

func NewImageClient(conn *grpc.ClientConn) *ImageClient {
    return &ImageClient{conn: conn}
}

func (ic *ImageClient) SendImage(imagePath string) (string, error) {
    // Implementation
}
```

### 6. Update client main.go

Edit `cmd/client/main.go` để call method mới.

## 📝 API Reference

**Request:** `FileChunk` (streaming)
```protobuf
message FileChunk {
  string filename = 1;
  bytes data = 2;
  int32 chunk_index = 3;
  int32 total_chunks = 4;
  Metadata metadata = 5;
}
```

**Response:** `ProcessFileResponse`
```protobuf
message ProcessFileResponse {
  ProcessingStatus status = 1;
  string result = 2;
  map<string, string> data = 3;
}
```

### ProcessJson - Gửi JSON

**Request:** `JsonRequest`
```protobuf
message JsonRequest {
  string json_data = 1;
  Metadata metadata = 2;
}
```

**Response:** `JsonResponse`
```protobuf
message JsonResponse {
  ProcessingStatus status = 1;
  string result = 2;
  map<string, string> data = 3;
}
```

## 💡 Ví dụ sử dụng

### Python (Server Handler)

```python
from handlers.file_handler import FileHandler
from handlers.json_handler import JsonHandler

# Xử lý file
result = FileHandler.process_file(file_data, filename)

# Xử lý JSON
result = JsonHandler.process_json(json_string)
```

### Go (Client)

```go
// Gửi JSON
jsonClient := NewJsonClient(conn)
result, err := jsonClient.SendJson(`{"name": "John"}`)

// Gửi file
fileClient := NewFileClient(conn)
result, err := fileClient.SendFile("./test.txt")
```

## 🔌 Mở rộng

### Thêm method mới trong Service

1. Thêm định nghĩa trong `proto/data_transfer.proto`
2. Chạy `./scripts/gen_proto.sh`
3. Implement handler trong Python `handlers/`
4. Implement servicer trong `python_server/server.py`
5. Gọi từ Go client

### Tùy chỉnh logic xử lý

- **File Handler**: Sửa `python_server/handlers/file_handler.py`
- **JSON Handler**: Sửa `python_server/handlers/json_handler.py`

## 🐛 Troubleshooting

### "grpc_tools.protoc not found"
```bash
pip install grpcio-tools
```

### "protoc not found"
```bash
# Ubuntu/Debian
sudo apt-get install protobuf-compiler

# macOS
brew install protobuf
```

### Connection refused
- Kiểm tra server đang chạy: `lsof -i :50051`
- Kiểm tra firewall settings
